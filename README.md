# gym-training-plan

Esqueleto inicial: React 18 + TypeScript + Vite + Vitest.

La implementación previa (catálogo, reproductor, panel admin y usuarios de prueba) está en la rama `implementacion-avanzada-con-ususario-de-prueba`.

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — typecheck + build
- `npm run typecheck` — `tsc --noEmit`
- `npm test` — tests con Vitest

## Agentes de IA

- `.claude/` — rules y skills de Claude Code
- `.kiro/` — agentes, skills, steering y specs de Kiro
- `.agents/` — rules y skills genéricas
