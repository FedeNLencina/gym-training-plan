# Directrices de Eficiencia y Concisión

- **Modificaciones de código:** No reescribas archivos completos. Muestra únicamente las funciones o bloques afectados, o aplica diffs directos.
- **Sin explicaciones redundantes:** Omite introducciones, resúmenes de cortesía y justificaciones teóricas a menos que se soliciten explícitamente.
- **Enfoque directo:** Ve directo a la implementación o solución del error.
